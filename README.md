# 🧠 Jogo da Memória com Emojis

Jogo da memória feito com **HTML, CSS e JavaScript puro**, sem frameworks e sem dependências.

## ✨ Recursos

- 16 cartas (8 pares) com flip 3D
- Embaralhamento justo (Fisher-Yates)
- Contador de jogadas e cronômetro
- Recorde salvo no navegador (`localStorage`)
- Animações para acerto e erro
- Tela de vitória com confete de emojis
- Botão de reset que reembaralha sem recarregar a página
- Responsivo (funciona no celular)
- Acessível: navegação por teclado (Tab, Enter e Espaço), leitor de tela e `prefers-reduced-motion`

## ▶️ Como rodar

Abra o `index.html` no navegador ou use a extensão **Live Server** do VS Code.
